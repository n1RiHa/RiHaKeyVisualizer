**RiHa Key Visualizer**

A simple mod that displays key presses as RiHa.

You can move the overlay, change its size and opacity, and replace the default images with your own.

By default, the mod uses the `E` and `P` keys, but you can set your own keys in the settings.

Based on [OttoKeyViewer](https://github.com/rdzip/OttoKeyViewer).
